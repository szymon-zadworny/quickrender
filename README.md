# Quickrender

![Quickrender](/docs/img/asteroids.png)

A modern WebGPU renderer written in Rust

## Features
- GLTF scene tree import support
- OBJ model import support
- Blinn-phong shading
- Textures
- Normal maps
- Mipmapping
- Simple mouse and keyboard navigation

## Controls
| Control | Action          |
|---------|-----------------|
| WASD    | Movement        |
| Mouse   | Camera rotation |
| Space   | Camera up       |
| C       | Camera down     |
